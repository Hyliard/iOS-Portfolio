# iOS Portfolio

Landing page de mi portafolio como desarrollador iOS (Swift, SwiftUI, SwiftData).

Un solo archivo `index.html` con HTML y CSS, sin dependencias ni proceso de compilación. Se adapta al modo claro/oscuro del sistema.

## Ver localmente

```sh
python3 -m http.server 8000
```

Abrir `http://127.0.0.1:8000`.
